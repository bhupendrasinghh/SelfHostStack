Vaultwarden Docker Compose Setup: Production Guide with Backups & SSL

By Ashirwad Pratap Singh • October 7, 2026 • Target: vaultwarden docker compose | KD: 18 | Vol: 1,600/mo

Prerequisites: A Linux VPS with Docker Engine 26+ installed, a custom domain pointed to Cloudflare, and Nginx configured as a reverse proxy. See our Zero-to-Production VPS Guide first.

Vaultwarden is a lightweight, open-source, Bitwarden API-compatible server written in Rust. It consumes approximately 10–30 MB of RAM (versus Bitwarden's official server which requires ~2GB), making it ideal for deployment on any budget cloud VPS. All official Bitwarden browser extensions and mobile applications work natively with Vaultwarden.

Architecture Overview

Internet
  └── Cloudflare (TLS 1.3, Full Strict SSL, CDN)
        └── Nginx Reverse Proxy (Port 443 → :8080)
              └── Vaultwarden Container (Port 8080)
                    └── SQLite Database File (./vw-data/)

Step 1: Docker Compose Manifest (Compose V2 Syntax)

Create your project directory and compose file:

mkdir -p ~/stacks/vaultwarden && cd ~/stacks/vaultwarden
nano docker-compose.yml
services:
  vaultwarden:
    image: vaultwarden/server:latest
    container_name: vaultwarden
    restart: unless-stopped
    environment:
      DOMAIN: "https://vault.yourdomain.com"
      SIGNUPS_ALLOWED: "false"          # Disable public registrations
      ADMIN_TOKEN: ""                   # Set a strong token for /admin panel
      WEBSOCKET_ENABLED: "true"
      LOG_LEVEL: "warn"
      EXTENDED_LOGGING: "true"
    volumes:
      - ./vw-data:/data
    ports:
      - "8080:80"
      - "3012:3012"                     # WebSocket notifications

Step 2: Nginx Reverse Proxy Configuration

sudo nano /etc/nginx/sites-available/vault.yourdomain.com
server {
    listen 80;
    server_name vault.yourdomain.com;

    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # WebSocket support for real-time sync
    location /notifications/hub {
        proxy_pass http://localhost:3012;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
sudo ln -s /etc/nginx/sites-available/vault.yourdomain.com /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

Step 3: Launch Vaultwarden

docker compose up -d
docker compose ps
docker compose logs vaultwarden

Step 4: Automated SQLite Backup Cron Job

Vaultwarden uses a SQLite database stored in ./vw-data/db.sqlite3. Set up a daily encrypted backup:

sudo crontab -e
# Run Vaultwarden SQLite backup daily at 2:00 AM
0 2 * * * docker exec vaultwarden sqlite3 /data/db.sqlite3 ".backup /data/db-backup-$(date +\%Y\%m\%d).sqlite3" && \
  gzip /home/deploy_admin/stacks/vaultwarden/vw-data/db-backup-$(date +\%Y\%m\%d).sqlite3 2>&1 \
  | tee -a /var/log/vaultwarden-backup.log
