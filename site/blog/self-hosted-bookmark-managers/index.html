Best Self-Hosted Bookmark Managers (2026): Linkding vs Karakeep vs Linkwarden

Target: self hosted bookmark manager | KD: 14 | Vol: 590/mo

Browser bookmarks are notoriously fragile — tied to a single browser profile, lost during OS reinstalls, unsearchable, and siloed. The growing self-hosting community has responded with a new generation of privacy-first, web-archival bookmarking platforms. This guide evaluates the three leading options based on actual deployment on a 1 GB RAM VPS.

1. Linkding — Ultra-Lightweight Minimalist Champion

Linkding is a single-container Django application that does exactly one thing well: bookmarks. At under 50 MB of RAM at idle using SQLite, it runs comfortably on the cheapest VPS instances available. Its API-first design and browser extension make it an excellent choice for developers who prefer simplicity over feature bloat.

Linkding Docker Compose

version: "3"
services:
  linkding:
    image: sissbruecker/linkding:latest
    environment:
      LD_SUPERUSER_NAME: admin
      LD_SUPERUSER_PASSWORD: CHANGE_THIS_STRONG_PASSWORD
    ports:
      - "9090:9090"
    volumes:
      - linkding_data:/etc/linkding/data
    restart: unless-stopped
volumes:
  linkding_data:

2. Karakeep (Hoarder) — AI-Powered Smart Archiving

Karakeep (formerly Hoarder) is the most feature-rich option. Its standout capability is AI-powered automatic tagging — save a bookmark and the local LLM (Ollama) or OpenAI API automatically classifies it into relevant categories. Full-page screenshots and PDF snapshots provide a true web archival layer.

Resource Note: Karakeep with local Ollama AI requires at least 4–8 GB RAM for the AI model. For budget VPS deployments, configure it with the OpenAI API key instead, reducing RAM to ~280 MB.

3. Linkwarden — Best for PDF Web Archiving

Linkwarden is a collaborative bookmark manager focusing on preservation — every saved link is automatically archived as a full PDF snapshot locally, ensuring you never lose content to link rot. It supports team collections with granular read/write permissions.
